# Reliquary

A medieval-fantasy monster-binding RPG set in Hollowmere. Bind the wild. Keep the old roads.

## Play

```bash
npm install
npm run dev
```

Then open the app in a browser. WASD or the on-screen pad to walk; Z / A to speak; X / B to back out; M for the menu.
